# TstoryBlog2 — 티스토리 전용

- 블로그: https://takeanews.tistory.com/
- `run.py`: 이 블로그 설정으로 공통 코드를 실행하는 진입점
- `../shared/`: 티스토리 공통 실행·노션·이미지·게시 코드
- `settings.py`: 이 블로그의 주소·환경변수 이름·카테고리 설정
- `../../.env`: 공통 토큰과 이 블로그의 데이터소스 ID
- `profiles/`: 이 블로그 로그인 정보만 저장 (공유 금지)
- `exports/`: HTML 백업 파일
- `../../images/tistory/TstoryBlog2/`: 이 블로그 전용 이미지 폴더

## 실행
최상위 폴더의 `.env`를 준비하고 이 폴더에서:

```powershell
notepad ..\..\.env
python run.py check
python run.py list
python run.py login
python run.py preview --number 19
python run.py draft --number 19
```

`draft --number`는 중간 입력 없이 해당 글의 임시저장을 시도합니다. 저장된 임시글을 다시 불러와 확인한 뒤 노션 상태를 기록합니다.

번호 19는 예시입니다. 실제 노션 데이터에 있는 번호를 사용하세요.
자동 입력이나 임시저장 확인이 실패하면 노션 체크박스를 업데이트하지 않고 중단합니다.
두 티스토리 블로그가 같은 게시 코드를 사용합니다. HTML 입력 후 기본모드로 돌아와 맞춤법 검사도 진행합니다. 노션의 카테고리 값을 읽어 같은 이름의 티스토리 카테고리를 선택합니다.

## 노션 필수 속성
| 속성 | 유형 | 용도 |
|---|---|---|
| 번호 | 숫자 | 선택할 글 번호 |
| 글 제목 | 제목 | 블로그 글 제목 |
| 작성여부 | 체크박스 | 작성 완료 여부 |
| 게시여부 | 체크박스 | 이미 실제 공개 게시됐는지 |
| 임시저장여부 | 체크박스 | 이 프로그램으로 저장 확인됨 |
| 임시저장일 | 날짜 | 선택 사항, 임시저장 시간 |
| 임시저장URL | URL | 선택 사항, 에디터 URL 보관 |
| 카테고리 | 선택 | 필수. 같은 이름의 티스토리 카테고리를 선택한 뒤 임시저장 |

각 글 페이지의 본문에 **HTML 코드 블록**(또는 HTML이 들어있는 YAML 코드 블록)을 넣으세요.
기존의 `게시여부`, `발행일`은 임시저장 시 변경하지 않습니다.

## 로컬 이미지와 대표 이미지

- 노션의 **책 이름** 속성에서 ALT의 핵심 단어를 가져옵니다. 해당 속성이 없다면 글 제목을 사용합니다.
- 원고의 `<img>`에 ALT가 비어 있으면 `책 이름 + 이미지 설명`으로 보충합니다. 기존 ALT가 있으면 그대로 유지합니다.
- `IMAGE:01`로 넣은 첫 번째 이미지를 티스토리 대표 이미지로 선택한 뒤 임시저장합니다. 저장한 글을 다시 불러와 서버의 `thumbnail`이 01번 이미지와 일치하는지 확인합니다. 티스토리 편집기는 임시글을 다시 열 때 `대표` 버튼을 선택되지 않은 모양으로 표시할 수 있습니다.
- 업로드한 이미지 아래 캡션에는 이 블로그의 노션 이름 속성(`TSTORY_BLOG2_PROP_AI_NAME`) 값을 자동으로 입력합니다.
- 노션 글의 `<!-- IMAGE:01 -->`은 이 블로그 이미지 폴더의 `번호_책 이름.png` 파일과 연결됩니다. `IMAGE:02`부터는 `번호_책 이름_02.png`처럼 번호를 붙입니다.
- `preview`는 파일 매칭만 확인하고, `draft`는 Playwright로 사진을 업로드해 표시 위치와 뒤따르는 빈 `<img src="">`를 교체합니다. 파일이 없거나 이름이 중복되면 임시저장 전에 중단합니다.
- `python run.py preview --number 19`를 실행하면 `exports/`에 HTML과 `.images.json` 작업 계획 파일이 만들어집니다.
- 노션에만 첨부된 이미지의 자동 다운로드는 지원하지 않습니다.


## 번호 범위로 임시저장 (v3)

```powershell
python run.py draft-range --from 1 --to 20 --dry-run
python run.py draft-range --from 1 --to 20
```

`--dry-run`으로 처리 대상과 제외 번호를 확인할 수 있습니다. 실제 실행은 중간 입력 없이 각 글을 순서대로 임시저장합니다.
저장된 임시글을 다시 불러와 확인한 경우에만 노션에 기록하고 다음 글로 넘어갑니다.
이미 공개되거나 임시저장 상태인 글, 작성 완료가 아닌 글, 번호 중복/누락 글은 자동 제외됩니다.
오류 또는 자동 확인 실패 시 즉시 멈추며, 공개 발행 버튼은 누르지 않습니다.
로컬 IMAGE 표시 이미지는 업로드하고 `IMAGE:01`을 대표 이미지로 지정합니다.
