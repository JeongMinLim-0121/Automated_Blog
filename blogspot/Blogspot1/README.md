# Blogspot1 — Blogger 전용

- 블로그: https://jmlim8038.blogspot.com/
- `run.py`: 이 블로그만 실행하는 명령어
- `notion_io.py`: 이 블로그의 노션 데이터 읽기/업데이트
- `publisher.py`: 이 블로그의 브라우저 입력/초안 저장 로직
- `settings.py`: 이 블로그의 고정 주소
- `../../.env`: 공통 토큰과 이 블로그의 데이터소스 ID 및 Blogger 블로그 ID
- `profiles/`: 이 블로그 로그인 정보만 저장 (공유 금지)
- `exports/`: HTML 백업 파일
- `../../images/blogspot/Blogspot1/`: 이 블로그 전용 이미지 폴더

## 실행
최상위 폴더의 `.env`를 준비하고 이 폴더에서:

```powershell
notepad ..\..\.env
python run.py check
python run.py list
python run.py login
python run.py preview --number 19
python run.py draft --number 19
```

번호 19는 예시입니다. 실제 노션 데이터에 있는 번호를 사용하세요.
초안 저장은 편집기 상태에 따라 수동 조작이 필요할 수 있으며, 사용자가 실제로 저장을 확인한 후에만 노션 체크박스를 업데이트합니다.

## 노션 필수 속성
| 속성 | 유형 | 용도 |
|---|---|---|
| 번호 | 숫자 | 선택할 글 번호 |
| 글 제목 | 제목 | 블로그 글 제목 |
| 작성여부 | 체크박스 | 작성 완료 여부 |
| 게시여부 | 체크박스 | 이미 실제 공개 게시됐는지 |
| 임시저장여부 | 체크박스 | 이 프로그램으로 저장 확인됨 |
| 임시저장일 | 날짜 | 선택 사항, 임시저장 시간 |
| 임시저장URL | URL | 선택 사항, 에디터 URL 보관 |
| 카테고리 | 선택 | 나중에 자동화를 확장할 때 사용 가능 |

각 글 페이지의 본문에 **HTML 코드 블록**(또는 HTML이 들어있는 YAML 코드 블록)을 넣으세요.
기존의 `게시여부`, `발행일`은 임시저장 시 변경하지 않습니다.


## 번호 범위로 임시저장 (v3)

```powershell
python run.py draft-range --from 1 --to 20 --dry-run
python run.py draft-range --from 1 --to 20
```

먼저 `--dry-run`으로 처리 대상과 제외 번호를 확인하세요. 실제 실행 전에는 `시작`을 입력해야 합니다.
매 글마다 편집기에서 초안 저장과 본문을 확인한 다음 `확인`을 입력해야 다음 글로 넘어갑니다.
이미 공개되거나 임시저장 상태인 글, 작성 완료가 아닌 글, 번호 중복/누락 글은 자동 제외됩니다.
오류 또는 확인 실패 시 즉시 멈추며, 공개 발행 버튼은 누르지 않습니다.
이미지 업로드/대표 설정은 여전히 자동화 대상이 아닙니다.
